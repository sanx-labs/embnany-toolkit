# EMBNANY Toolkit

> An all-in-one fan support & data engagement toolkit designed for **EmiBonnie** — streamlining X (Twitter) trend boosting, schedule tracking, Instagram EMV engagement, and voting aggregation.

🌐 **Live Demo:** [https://embnanytoolkit.vercel.app](https://embnanytoolkit.vercel.app)

---

## ✨ Core Modules

### 1. 📈 Trend Booster (`Trend`)
- **Rapid Copy Generation:** Instantly generates ready-to-post promotional copy paired with designated trending keywords and hashtags.
- **Multi-Artist Support:** Built-in artist selector to dynamically switch keywords and hashtags when boosting multiple artists concurrently on the same day.
- **One-Click Copy:** Instant clipboard copy for seamless posting on X.

### 2. 📅 Live Schedule (`Schedule`)
- **Real-Time Sync:** Powered by the **Notion API** to automatically sync upcoming online livestreams, media appearances, and offline events.
- **Clear Categorization:** Unified view of artist activities so fans never miss an event.

### 3. 📊 EMV Engagement (`EMV`)
- **Interactive Checklist:** Task-oriented checklist to track daily Instagram engagement goals.
- **Boost Guide & AI Prompts:** Includes actionable EMV optimization guidelines and built-in **AI Prompt Templates** (with one-click copy) to generate high-quality, authentic comments.

### 4. 🗳️ Voting Hub (`Vote`)
- **Card-Based Dashboard:** Clean, responsive event cards displaying active polls, platforms, and deadlines.
- **Live Data Sync:** Connected to a Notion database for real-time updates on ongoing and upcoming voting campaigns.

---

## 🛠️ Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend / CMS:** [Notion API](https://developers.notion.com/)
- **Deployment:** [Vercel](https://vercel.com/)
